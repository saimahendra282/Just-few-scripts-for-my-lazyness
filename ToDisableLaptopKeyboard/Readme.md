These scripts use the Windows Plug and Play feature to temporarily lock your laptop keyboard, because in case your keyboard is also in Stage 4 cancer like mine, we have to give it some rest, right? 😭

##

If you get any errors while running these scripts, such as Windows Smart App Control / SmartScreen blocking them, don't panic.

If you trust the scripts and know where they came from:

Right-click the script.
Click Properties.
In the General tab, look for the Unblock option.
Check Unblock.
Click Apply → OK.
Run the script again.

Do this for any script that Windows has blocked.
