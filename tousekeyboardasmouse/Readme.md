## how to use this ?

first download this dir and make sure to include ps and bat files in the same dir, of course u can change the names and paths but u have to update the same in the bat file if u did

run the start.bat file and choose which key u want to use as the toggle for mouse mode

once mouse mode is on:

* arrow keys - up, down, left and right mouse movement
* q - move diagonally up-left
* w - move diagonally up-right
* a - move diagonally down-left
* s - move diagonally down-right
* e - scroll up
* d - scroll down
* left shift - left click
* right shift - right click
* hold space , right shift , then arrow keys for dragging

run the stop.bat file to stop it completely

##
If you get any errors while running these scripts, such as Windows Smart App Control / SmartScreen blocking them, don't panic.

If you trust the scripts and know where they came from:

Right-click the script.
Click Properties.
In the General tab, look for the Unblock option.
Check Unblock.
Click Apply → OK.
Run the script again.

Do this for any script that Windows has blocked.
